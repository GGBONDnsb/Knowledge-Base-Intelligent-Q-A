# 云启低代码平台产品介绍

> 文档编号：YQ-PROD-001
> 版本：v1.4
> 生效日期：2026-08-18
> 责任人：产品部
> 权限级别：全员

## 1. 文档说明

云启低代码平台面向业务人员和开发人员，通过可视化表单、流程、页面和 API 编排，快速构建企业内部应用。

## 2. 产品定位

平台面向需要快速交付业务应用的中小企业，覆盖审批、报表、运营管理和轻量业务系统场景。

核心目标是降低开发门槛，同时保留专业开发的扩展能力。

## 3. 核心能力

- 可视化表单设计：支持 20 余种字段类型、校验规则和条件显隐。

- 流程引擎：支持会签、或签、条件分支、超时提醒和委托办理。

- 页面与报表：支持列表、看板、图表和数据透视。

- API 编排：通过连接器调用第三方系统，支持 Webhook。

- 权限体系：按角色、部门和数据范围控制访问。

## 4. 技术架构

前端采用响应式 Web 组件，后端服务由元数据驱动，数据存储支持关系数据库。

应用运行时包含表单引擎、流程引擎、规则引擎和集成网关四个模块。

部署方式支持单机、集群和容器化，企业可选择私有化部署。

## 5. 典型场景

人事场景：入职申请、考勤异常、绩效面谈记录。

行政场景：会议室预订、资产领用、用印申请。

业务场景：客户跟进、项目周报、采购审批。

## 6. 服务与支持

提供标准版、专业版和企业版，企业版包含私有化部署与专属技术支持。

实施服务包括需求梳理、应用搭建、数据迁移和员工培训。
