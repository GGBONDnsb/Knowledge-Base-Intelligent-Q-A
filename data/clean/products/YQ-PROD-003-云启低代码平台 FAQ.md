# 云启低代码平台 FAQ

> 文档编号：YQ-PROD-003
> 版本：v1.1
> 生效日期：2026-08-18
> 责任人：产品部
> 权限级别：全员

## 1. 文档说明

本 FAQ 汇总云启低代码平台的常见问题，覆盖部署、性能、集成和权限。

## 2. 部署与安装

问：云启低代码平台支持哪些部署方式？

答：支持 Docker Compose 私有化部署和 Kubernetes 集群部署，也提供 SaaS 托管版本。

问：私有化部署需要哪些资源？

答：最低建议 4 核 8GB 内存、50GB 磁盘，正式环境建议 8 核 16GB 并配置数据库备份。

## 3. 性能与容量

问：单应用最多支持多少条数据？

答：平台基于关系数据库，单表数据量建议控制在 500 万行以内，超出后建议归档或使用数据仓库。

问：流程并发高时如何优化？

答：优先扩展应用服务节点，合理设计流程节点数量，关闭不需要的日志。

## 4. 集成与扩展

问：可以调用企业已有系统的 API 吗？

答：可以，平台提供 HTTP 连接器、Webhook 和脚本节点，可调用 REST API。

问：支持二次开发吗？

答：企业版支持自定义代码包、前端扩展点和开放 API。

## 5. 权限与安全

问：数据权限支持到字段级吗？

答：专业版及以上支持字段级权限，普通版支持记录级和操作级权限。

问：系统是否支持审计日志？

答：支持登录、导出、删除和权限变更审计，日志保留 180 天。
