# 云启数据分析平台版本发布记录

> 文档编号：YQ-PROD-009

## 1. 文档说明

本文记录云启数据分析平台的版本更新内容，便于用户跟踪新功能和修复项。

## 2. v3.2（2026-05-20）

- 新增指标解释功能，支持在图表上查看口径说明。

- 新增数据血缘图，展示数据集和看板的引用关系。

- 优化大屏组件性能，支持 60 帧平滑刷新。

- 修复订阅任务偶发重复发送问题。

## 3. v3.1（2026-03-18）

- 新增 SQL 编辑器自动补全和慢查询提示。

- 支持看板间参数传递和跨看板跳转。

- 新增移动端查看模式。

## 4. v3.0（2026-01-12）

- 重构指标层，支持复合指标和同环比计算。

- 新增自助取数模块，业务人员可导出明细。

- 接入统一权限中心，支持部门级授权。
