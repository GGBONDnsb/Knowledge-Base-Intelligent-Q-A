# 云启 API 网关 FAQ

> 文档编号：YQ-PROD-023
> 版本：v1.0
> 生效日期：2026-08-18
> 责任人：产品部

## 1. 文档说明

本 FAQ 汇总云启 API 网关的常见问题，覆盖性能、限流、安全和高可用。

## 2. 性能问题

问：网关会增加多少延迟？

答：默认配置下 P99 新增延迟通常小于 5ms，实际与机器规格、插件数量有关。

问：如何提升网关吞吐？

答：增加网关节点、使用长连接、减少阻塞插件并合理配置连接池。

## 3. 限流问题

问：限流是按单节点还是集群统计？

答：默认单节点统计，集群限流可启用分布式限流组件。

问：被限流后请求如何处理？

答：返回 429 和 Retry-After 头，客户端应做退避重试。

## 4. 安全与高可用

问：如何防止恶意调用？

答：启用认证、IP 黑名单、动态限流和签名校验，并接入 WAF。

问：网关节点故障是否影响业务？

答：多节点部署下负载均衡会自动摘除故障节点，控制面变更不受影响。
