# 云启 API 网关配置示例

> 文档编号：YQ-PROD-025
> 版本：v1.1
> 生效日期：2026-08-18
> 责任人：技术支持部
> 权限级别：管理员

## 1. 文档说明

本文提供云启 API 网关的典型配置示例，包括路由、JWT 认证、限流和灰度。

## 2. 基础路由

以下配置将 /api/v1/orders 转发到订单服务，并启用 JWT 认证。

```yaml

routes:

  - name: order-api

    methods: [GET, POST]

    paths: ['/api/v1/orders/*']

    upstream: order-service:8080

    auth: jwt

```

## 3. JWT 认证

在认证插件中配置签发者、公钥或 JWKS 地址。

验证签名和过期时间，可选校验 audience。

认证失败返回 401，缺少权限返回 403。

## 4. 限流配置

按消费者限流示例：每个应用每秒 50 次，突发 100 次。

```yaml

rate_limit:

  scope: consumer

  qps: 50

  burst: 100

```

限流响应统一格式，便于客户端处理。

## 5. 灰度发布

按请求头分流：包含 canary: true 的请求进入新版本服务。

```yaml

canary:

  match:

    header: canary

    value: 'true'

  upstream: order-service-canary:8080

```

灰度流量应配置独立监控指标，观察错误率和延迟。
