# 云启 API 网关用户手册

> 文档编号：YQ-PROD-022
> 版本：v1.2
> 生效日期：2026-08-18
> 责任人：产品部
> 权限级别：全员

## 1. 文档说明

本手册介绍云启 API 网关的路由、认证、限流、插件和监控配置方法。

## 2. 创建服务与路由

在网关控制台创建上游服务，配置协议、负载均衡和目标地址。

创建路由时绑定服务，设置路径、方法、域名和优先级。

灰度路由按 Header、Cookie 或流量比例分发。

## 3. 认证配置

全局或按路由启用认证插件，支持 JWT、API Key、OAuth2。

开放平台可创建应用并分配 API Key，设置配额和有效期。

密钥泄露时可在控制台立即吊销并重新生成。

## 4. 限流与熔断

限流策略支持按路由、消费者或客户端 IP 配置 QPS 和并发。

熔断策略设置错误率阈值、熔断持续时间和恢复窗口。

限流超限返回 429，并附带重试时间提示。

## 5. 插件与观测

插件按请求流程分为认证、转换、安全和观测类型，可在控制台启用和排序。

网关提供调用统计、Top 接口、延迟分布和错误日志。

链路追踪可对接 Jaeger 等系统。
