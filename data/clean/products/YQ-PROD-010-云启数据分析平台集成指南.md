# 云启数据分析平台集成指南

> 文档编号：YQ-PROD-010
> 版本：v1.0
> 生效日期：2026-08-18
> 责任人：技术支持部
> 权限级别：部门

## 1. 文档说明

本指南说明云启数据分析平台与外部系统的集成方式，包括开放 API、SSO 和消息通知。

## 2. 开放 API

平台提供 REST API，可查询数据集、创建看板、触发刷新和获取导出任务。

API 使用访问令牌认证，令牌可设置有效期和权限范围。

## 3. SSO 集成

支持 OIDC、SAML 和 OAuth2 协议，对接企业统一身份认证。

集成后在用户中心配置回调地址，并同步组织架构和部门映射。

## 4. 消息与自动化

预警和订阅结果可推送至企业微信、钉钉、邮件和 Webhook。

数据任务可纳入统一调度平台，通过 API 触发执行。

## 5. 安全建议

集成账号使用最小权限，生产数据源使用只读账号。

API 密钥妥善保存，禁止写入前端代码或公共仓库。
