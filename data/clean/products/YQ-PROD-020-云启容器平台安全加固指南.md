# 云启容器平台安全加固指南

> 文档编号：YQ-PROD-020
> 版本：v1.1
> 生效日期：2026-08-18
> 责任人：信息安全部
> 权限级别：管理员

## 1. 文档说明

本指南提供云启容器平台的安全加固建议，覆盖平台基线、镜像供应链、运行时安全和审计。

## 2. 平台基线

控制面禁止公网直接暴露，管理端口通过堡垒机访问。

使用 RBAC 最小授权，管理员账号启用 MFA。

关闭不需要的 API 匿名访问和仪表盘端口。

## 3. 镜像供应链

基础镜像锁定 tag 和摘要，构建过程使用最小化基础镜像。

上线前扫描镜像漏洞，阻断高危和高危以上镜像。

镜像签名和准入策略联动，未签名镜像禁止部署。

## 4. 运行时安全

应用以非 root 用户运行，设置只读根文件系统和资源限制。

启用 seccomp、AppArmor 和网络策略，限制容器权限。

敏感信息通过密钥管理注入，禁止明文环境变量。

## 5. 审计与监控

开启 API 审计、容器事件和登录日志，集中存储并设置保留周期。

配置异常行为告警，例如特权容器启动、集群内横向访问和密钥泄露。

每季度开展一次安全基线巡检并输出整改报告。
