# 云启 API 网关产品介绍

> 文档编号：YQ-PROD-021
> 版本：v1.5
> 生效日期：2026-08-18
> 责任人：产品部
> 权限级别：全员

## 1. 文档说明

云启 API 网关统一管理企业 API 的接入、认证、限流、转发和监控，帮助团队安全高效地开放服务。

## 2. 产品定位

网关位于客户端与后端服务之间，提供统一的访问入口。

适合微服务架构、开放平台和对内服务治理场景。

## 3. 核心能力

- 路由管理：路径、域名、权重和灰度路由。

- 认证鉴权：JWT、OAuth2、API Key、IP 白名单和签名。

- 流量控制：QPS 限流、并发控制和熔断降级。

- 协议转换：HTTP 与 gRPC 互转、WebSocket 代理。

- 观测能力：调用日志、链路追踪、错误告警和报表。

## 4. 架构说明

控制面管理路由与策略，数据面负责流量转发，支持多环境隔离。

网关节点无状态，可水平扩展；策略变更通过热加载生效。

支持集群部署和跨可用区容灾。

## 5. 典型场景

开放平台：统一认证、配额管理和开发者门户。

微服务治理：服务发现、灰度、熔断和可观测。

安全防护：防刷、参数校验、敏感数据脱敏。
